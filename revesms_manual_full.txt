     Client
     SMS Client
     In REVE SMS there are 3 types of clients:
         1. Originating
         2. Terminating
         3. Reseller


      Type of Clients           Description
      Originating               Originating client can send SMS to this platform using SMPP/HTTP protocol.
                                Also originating client can use this platform interface to send bulk SMS
                                through campaign.
      Terminating               Terminating client is used as a gateway to terminate SMS request coming from
                                originating client.
      Reseller                  Reseller client can resell this platform to another client. They can create new
                                originating client and reseller under them and create their offer to other
                                clients.
